# StriveX - High-Performance Fitness Ecosystem

A responsive web application for fitness center operations, personal training management, workout logging, and administrative analytics.

## Tech Stack
- Framework: React 19 + Vite
- Styling: Kinetic Glass Design System (Vanilla CSS, 40px glass blurs, dark/light themes)
- Icons: Lucide React
- Typography: Plus Jakarta Sans / Inter

## Viewports Supported
- Desktop: 1440px
- Mobile: 390px

## Key Modules
1. Public and Onboarding (Hero, Features, Class Schedules, Tiered Pricing, Multi-step Registration, Role-aware Login)
2. Member Experience (Athlete Dashboard, Dynamic Goal Rings, Active Workout Session Logger, Settings, Trainer Chat)
3. Trainer Portal (Client Roster, Biometrics, Interactive Workout Routine Builder, Messaging)
4. Admin Operations (Executive KPIs, Financial Reports, Transaction Ledger, Staff Management, Global Search)

## Running the Application Locally
```bash
npm install
npm run dev
```
